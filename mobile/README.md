# AquariusEcoCase Mobile App

Мобильное приложение на React Native для мониторинга данных сенсоров AquariusEcoCase.

## Установка

1. Установите зависимости:
```bash
npm install
```

или

```bash
yarn install
```

2. Запустите приложение:
```bash
npm start
```

или

```bash
expo start
```

3. Отсканируйте QR-код в приложении Expo Go на вашем телефоне или нажмите:
   - `i` для запуска в iOS симуляторе
   - `a` для запуска в Android эмуляторе

## Структура проекта

```
mobile/
├── App.js                 # Главный компонент приложения
├── src/
│   ├── screens/           # Экраны приложения
│   │   ├── DashboardScreen.js      # Главный экран с датчиками
│   │   └── SensorDetailScreen.js   # Детальный экран датчика
│   ├── components/         # Компоненты
│   │   └── SensorCard.js           # Карточка датчика
│   ├── services/           # Сервисы
│   │   └── sensorService.js        # API для работы с данными
│   └── config/            # Конфигурация
│       └── api.js                   # Настройки API
└── package.json
```

## Функциональность

- 📊 Отображение данных всех датчиков в реальном времени
- 🔄 Автоматическое обновление каждые 5 секунд
- 📈 Графики для каждого датчика
- 📱 Pull-to-refresh для ручного обновления
- 🎨 Современный и интуитивный интерфейс

## API

Приложение использует публичный API endpoint:
- `GET http://82.202.142.35:5000/api/mobile/sensor-data?device=esp01`

## Требования

- Node.js 16+
- npm или yarn
- Expo CLI
- Expo Go приложение на телефоне (для тестирования)

## Разработка

Для разработки используйте:
```bash
npm start
```

Затем выберите платформу (iOS/Android) или отсканируйте QR-код.
